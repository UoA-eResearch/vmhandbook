You will need to:

- Set up [Two-Factor Authentication (2FA)](https://www.auckland.ac.nz/en/about-us/about-the-university/identity-and-access-management/two-factor-authentication.html) if you haven't already.
- Install and configure [VPN software](https://www.auckland.ac.nz/en/students/academic-information/postgraduate-students/postgraduate/postgraduate-support-and-services/vpn-service.html).
- Map the Research Drive to your computer (see instructions for [Windows]({{ site.baseurl }}{% link _doc/map-drive-windows.md %}), [Mac]({{ site.baseurl }}{% link _doc/map-drive-mac.md %}), or [Linux]({{ site.baseurl }}{% link _doc/mount-drive.md %})).
